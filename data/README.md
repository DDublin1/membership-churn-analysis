# Data

Dataset not included in this repository due to file size (2.1GB, 18.4M rows). The pipeline expects a CSV file at `data/churn_t_db.csv`.

To run the full analysis pipeline, provide your membership dataset in the following format:
- **Location**: `data/churn_t_db.csv`
- **Size**: Approximately 2.1GB (18.4M rows)
- **Format**: CSV with membership records including churn indicators and behavioral features

See the notebooks for specific column requirements and data schema expectations.
